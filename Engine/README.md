# Paper Almanac daily engine

This local Swift package exposes the `TungShingDailyAlmanac` product. It supplies offline day reports, solar terms, Celestial Almanac annotations, and Fuji holidays. The source was extracted from the engine revision `3fa6e7899d839aa39900510c963b062b29a854ca` with the six targets used by the daily product. The package carries the daily runtime tables and their provenance. The source revision and research paths in the provenance identify records in the development archive.
