# Third-party notices for TungShingAlmanac

The `TungShingAlmanac` target is a Swift port of the almanac evaluator and its tables from
**OPN48/cnlunar**, pinned at commit `3f674fe0f458b480c79eaaf5464f43f4bc815a91`

`cnlunar/config.py`, `cnlunar/solar24.py`, `cnlunar/tools.py` and `cnlunar/holidays.py`.
Source Simplified Chinese tokens are retained as stable identifiers.

# Notices for TungShingCore

## Historical clock before 1972 (S15.2020)

`HistoricalUT1.swift` carries the nineteen 1895–1974 segments of Table S15.2020, the cubic spline of ΔT
(TT − UT1) in L. V. Morrison, F. R. Stephenson, C. Y. Hohenkerk and M. Zawilski, Addendum 2020 to
"Measurement of the Earth's rotation: 720 BC to AD 2015", supplementary dataset version 2,
doi:10.6084/m9.figshare.13885863.v2 (https://rs.figshare.com/articles/dataset/13885863/2).
Licence: Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/).

Modification notice: the coefficients are the binary64 values that Skyfield 1.55 stores, which truncate
the spline where Skyfield's daily table begins and adjust the 1971–1974 segment's linear coefficient
(printed 3.157, stored 3.4897025899490037). They were taken from the research reference
`tung-shing-research/docs/handoff/calendar-pack/review/ut1-historical-clock/COEFFICIENTS.json` at commit
`21568ea8b4286d4772a9ef989366f2bec937eb39` (profile `HK8-S15-SKYFIELD155-REAL-UT1-1972-UTC-v1`). The
research does not certify the model's physical accuracy; the app treats it as a named convention with a
stated time budget.

Celestial Almanac Japanese lunar context
CAL-DE440S-REAL-UTC9-K37-DAY-1901-2100-v1, fixed +09:00, frozen K=37.
Own narrow extraction from the admitted regional-lunar-calendars-1 model calendar. Calculated from JPL DE440 short kernel (Park et al. 2021; NAIF rules https://naif.jpl.nasa.gov/naif/rules.html; no NASA/JPL endorsement implied). The source UTC+09 table was compared with NAOJ calendar summaries 2004–2027; no NAOJ endorsement implied. Model days; no physical-accuracy claim. Daily nine-star adopts the explicitly named Koyomi8 nearest-kinoene intercalation convention; rules were implemented independently without copying website text or code.

Celestial Almanac elapsed lunar age
Own compact extraction of certified DE440-derived conjunction roots, model DE440S-SKYFIELD155-SCALAR-REAL-v1. NASA/JPL DE440, NAIF and Skyfield 1.55 acknowledged above. The runtime contains only 2476 millisecond-rounded TT timestamps, not an ephemeris. The celestial reading uses 12:00 fixed reference UTC / frozen K37; numerical root precision does not certify physical or historical civil-clock accuracy. Canonical provenance: runty/tung-shing-research docs/research/celestial-almanac/SKY_METHOD.md and MOON_AGE_REFERENCE.json.
